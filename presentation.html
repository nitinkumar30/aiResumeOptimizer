🔩 Core Intelligence Nodes

The three-stage AI pipeline

🧠 Stage 1: Resume Intelligence

Parses resume with strict anti-hallucination rules:

  • Multi-role consolidation for career progression
  • Project-to-employer mapping by date alignment
  • Two-column layout fragment reassembly
  • Date standardization (Sept '21 → September 2021)

🧠 Stage 2: JD Intelligence

Detect-only analysis — no inference:

  • Domain classification (15 categories)
  • Must-have vs. good-to-have skills
  • Responsibility mapping (Core/Secondary/Strategic/Operational)
  • Keyword priority ranking (High/Medium/Low)

✍️ Stage 3: ATS-Optimized Generation

Fills locked LaTeX skeleton:

  • Action verbs: Designed, Automated, Optimized, Built
  • JD keywords injected naturally — no stuffing
  • Skills reordered by JD priority
  • pdflatex-compilable output guaranteed

📊 ATS Scoring Formula

0-100 based on 4 weighted factors:

  • Keyword coverage (40%) — High-priority matches
  • Skills alignment (30%) — Must-have vs. present
  • Experience relevance (20%) — Years + domain
  • Role title alignment (10%) — Seniority match

🛠️ Setup Guide

5 steps to go from zero to generating resumes

📥 1. Import Workflow

n8n → Workflows → Import → Upload OptimizeResumeAsPerJD — Enhanced.json

🔑 2. Configure AI Credentials

Add Google PaLM API (Gemini) + OpenAI API key credentials in n8n Settings

🤖 3. Create Telegram Bot

Use @BotFather → /newbot → Copy token → Add as credential in n8n

🆔 4. Get Chat ID

Message bot → Visit api.telegram.org/bot<TOKEN>/getUpdates → Copy chat.id

✅ 5. Activate & Share

Toggle Active → Copy Production URL from Form Trigger → Share with anyone

📱 6. Optional: Media APIs

Add API keys for DALL-E, Veo, Sora, Grok, Seedance for media generation
